# Pidance UI 重做设计稿（OpenChamber v1.18.1 参考）

本轮替换上一轮 Slate／Linen／Neon 三套方案。设计研究参考 OpenChamber v1.18.1 的界面与主题（`MainLayout`、`SessionNodeItem`、`ChatMessage`、`SettingsView`、`ArchiveView` 与 light/dark 主题文件），并核对了以下上游改动：

- `e6802123`：深色底由近黑调整为更柔和的暖墨色 `#120f0e`，前景收敛为 `#c9c5ba`，选中态改为低彩暖灰。
- `faa9c243`：会话运行状态由持续旋转图标改为静态圆点 + 轮次计时，降低列表噪声。
- `ffbd139c`：归档页采用固定筛选栏、紧凑列表、搜索与悬浮动作；Pidance 当前无归档页，因此只借鉴其列表密度和动作显隐方式，不加入归档功能。

## 冻结的信息架构

两套方向使用同一布局，不改变 Pidance 功能边界：

```text
桌面：268px 会话栏 │ 自适应聊天区（正文最大 760px） │ 320px 右侧工作区 + 40px rail
手机：顶部会话上下文 │ 聊天主区 │ 输入框 │ 4 项底部导航
                         └─ “会话”打开覆盖式左抽屉
```

- 左侧：Pidance 标识、新会话、搜索、最近会话、项目／工作树／会话树、底部项目与设置入口。
- 中间：会话顶栏、用户与助手消息、工具卡、代码块、运行提示、模型／思考／工具控制和输入框。
- 右侧：文件、Git 更改、会话信息三页签；不是 OpenChamber 的多功能 Context Panel。
- 设置：只保留外观、模型、默认值、技能、插件、信任六页，不带入 OpenChamber 的 Providers／Agents／MCP 等页面。
- 移动端：使用抽屉承载层级较深的会话树，底栏只保留会话、聊天、文件、更多四个顶层入口；不把复杂树压进底部弹层。

## 两套方向

| 方向 | 一句话定位 | 视觉签名 |
|---|---|---|
| **A · Chamber 原生** | 尽量贴近 OpenChamber 最新暖墨主题，把桌面开发工具的克制密度直接适配到 Pidance 网页端。 | 橙色运行圆点与等宽轮次计时嵌入会话树，暖灰整行选中态贯穿三栏。 |
| **B · Pidance 融合** | 保留 OpenChamber 的层级和密度，用冷静的“月光蓝 + 松针绿”建立更清楚的网页产品身份。 | 顶栏细蓝轨与青绿运行态形成双状态语言，长时间阅读更清爽。 |

每个 HTML 文件均为无外部依赖的静态稿，可直接用浏览器打开。方向 A 默认展示深色，方向 B 默认展示浅色；两套完整明暗值见 `theme-tokens.md`。

## OpenChamber 参考点对照

| 参考点 | Pidance 采用方式 | 原因 |
|---|---|---|
| 暖色低彩 surface 分层 | A 直接沿用接近当前值的暖墨／纸白；B 保留明度关系、改变色相 | 获得成熟开发工具气质，同时让两方向可辨。 |
| 侧栏紧凑树、整行 tint 选中 | 行高 30px、6px 圆角、完整行点击区域、层级导线 | 高频会话切换需要高密度和稳定扫描路径。 |
| 静态运行点 + 用时 | 左侧圆点，右侧 tabular 计时；未读用另一状态色并配文字提示 | 比 spinner 安静，且不只靠颜色表达状态。 |
| 助手消息开放排版 | 助手无大气泡，用户消息使用窄色块；正文宽度控制在 760px | 长回复阅读更自然，角色仍清楚。 |
| 工具块和代码块 | 低对比边框、单行标题、状态／耗时靠右，代码嵌入展开区 | 保持执行轨迹可扫读，不与正文争抢。 |
| 设置固定导航 | 240px 导航 + 单一内容页，导航行选中为 surface tint | Pidance 设置项少，不复制 OpenChamber 的三级设置结构。 |
| 归档页列表模式 | 只借鉴搜索、分组、悬浮动作和批量列表密度 | Pidance 没有归档功能，刻意不扩张功能清单。 |

## 刻意不抄的部分

1. 不复制 Electron 标题栏、交通灯、安全区和窗口拖拽区域；Pidance 顶栏按浏览器窗口设计。
2. 不引入 OpenCode、Plan、Multirun、MCP、Usage、Remote Instances、Archive 等 Pidance 不具备的入口。
3. 不照搬 OpenChamber 移动端全宽双抽屉；Pidance 的右侧内容用底部“文件／更多”进入，减少手势冲突。
4. 不复制品牌图形和专有图标；实现统一用 `lucide-react`，设计稿用无依赖内联 SVG 表意。
5. 不使用持续脉冲、霓虹发光或大面积玻璃效果；运行状态依靠静态点、文字与计时共同表达。

## 落地优先级

1. 先统一 token、字体、边框与三栏 surface；不动组件职责。
2. 再重做会话树行、运行／未读状态和消息排版。
3. 然后统一工具卡、代码块、输入框与右栏 tabs。
4. 最后调整设置响应式与移动抽屉；动效只做抽屉进出和运行状态切换。
