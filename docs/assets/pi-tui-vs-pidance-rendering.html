映射通道：插件渲染函数（renderCall / renderResult / setWidget 工厂 / registerMessageRenderer） → Pidance server 端 headless 执行 Component.render(width) → ANSI 行 → 经 extension_ui_request SSE 推送 → 前端 renderAnsiLine() （ChatWindow.tsx:928，已存在）转成 React 内联样式。 左栏与右栏内容完全同源 —— 同一份插件代码、同一组语义色，只是终端字符 vs Web 卡片两种呈现。
说明：左栏为 pi TUI 实际渲染形态（源自 pi-subagents 0.35.1 的 renderSubagentResult / buildWidgetComponent / SubagentControlNoticeComponent 源码结构，ANSI 色按语义还原）； 右栏为 Pidance 渲染桥建立后的目标形态（近似现有 ToolCallBlock / ExtensionWidgets / InlineExtensionCard 的视觉语言）。交互式部件（select/confirm/input/editor/custom）不走此通道， 仍由现有 extension-ui-bridge 处理。
