# v0.2.35

包：`@henlii/pidance` · CLI：`pidance`

## 中文

### 状态同步重做（这一版的主要工作）

- **偏好写入只发脏键**：客户端不再把整份内存快照 PUT 回服务端 —— 一次无关写入会把没改过的字段一起
  写回，实测**把用户的项目列表清空过**、也把 `locale` 从中文写成英文。现在只发本次真正改动的点路径，
  `null` 用作删除墓碑，宿主独占键（`sessionQueue*`）永不回写。
- **集合改「命令」语义 + revision 广播**：项目列表/置顶/未分组/折叠这些集合字段改为在服务端**文件锁内**
  施加 `add`/`remove`，于是「两个标签各加一项」不再丢其中一项（这是旧实现的已知限制）。写入成功后服务端
  把**变更的键**广播给同一后端的所有客户端（复用运行集那条 SSE，不新开连接），同后端内亚秒级同步；
  断线/后台仍由「切回前台拉一次」兜底。
- **未读改跨端**：`completedAt` 由**服务端**在 run 结束时记录（即使当时没开浏览器也算数），`readAt` 由各端
  打开会话时记录，未读 ⟺ `completedAt > readAt`；两侧都是单调时间戳取并集，无需 CAS。本地那份降级为首屏缓存。
- **作用域定死**：窗口偏好（footer 折叠、引导页目标）与文件树展开/滚动改为**只存本机**；插件/技能锁改子键
  写入；设备注册表读-改-写加进程间锁；`docs/architecture.md` 新增「状态作用域与冲突规则」表与不变量。

### 侧栏

- **新增「未分组会话」区**：关闭项目的会话有了归宿（此前会整体隐藏），从未加入过项目的目录也算未分组；
  **重新添加项目不回迁**旧会话。全文搜索命中行、归档视图、最近/置顶区不再按项目过滤。
- **列表不再永久空着**：`/api/sessions` 请求加 10 秒超时 + 最多 2 次有界重试；此前请求被丢弃或卡住时，
  侧栏会一直停在「暂无会话」，只能刷新页面自愈。
- 旧模型迁移不再把「最近会话所在目录」并进共享项目列表（项目列表只由用户增删）。

### 聊天、文件与扩展面板

- 切回前台只恢复一次（focus 与 visibilitychange 同批合并），不再重复重连/重拉。
- 窗口标题所有权收归 AppShell：扩展 `setTitle` 变成有有效期的临时覆盖，不再被立刻打回。
- 打开/切换文件时立刻拉该文件 diff，「Git 差异」开关不再等文件变更才出现。
- 扩展提问弹窗：`select` 右上不再有与「取消」等价的「关闭」；长提问可滚动；新增「展开/收回」，默认展开。

### 子代理

- 异步子代理面板按 TUI 的行结构渲染（不再显示原始机器载荷），并去掉输入框下方那行里的终端键位提示。

### 桌面壳（Electron）

- **接线托盘设置入口与桌面通知**：托盘「桌面版设置…」现在会打开设置页的「桌面版」（此前点了没反应），
  三个开关（开机启动 / 关窗最小化到托盘 / 桌面通知）读写桌面壳自己的设置；窗口不在前台时会话跑完会发系统通知。

### 测试基建

- 浏览器回归套件改为**每条用例一个独立浏览器会话**，主套件连跑 3 轮全绿；未读跨端那条因高负载下会抖，拆到
  `npm run test:browser:unread` 单独跑。
- 补上跨进程租约的 Service 层直测（对端持锁时 `ensureLive`/`submitPrompt`/离线写全部 409 且**磁盘一个字节
  都没写**）、`?wake=1` 只在发送握手路径的门禁、以及「locked 判定只有一种写法」的门禁。

### 已知边界

- 未读跨端用例（`test:browser:unread`）在**高负载机器**上偶发失败：诊断显示浏览器侧连接饥饿（列表请求 10 秒
  拿不到响应）；已由上面的超时+重试保证用户侧不会永久空列表，但该用例本身仍可能红。
- 同一数组的并发加项现在由命令语义解决；但**用 patch 写集合**（例如手写 API 调用）仍会被整体替换 —— 规则见
  `docs/architecture.md`。
- 桌面壳的真实 Electron 冒烟只在 CI（Windows）跑；本地未安装 `desktop/` 依赖，页面侧用注入的 mock 桥验证。

## English

### State sync rework (the bulk of this release)

- **Preference writes now send only dirty keys.** The client no longer PUTs a whole in-memory snapshot, which could
  echo fields it never changed — in practice this wiped a user's project list and flipped `locale` to English.
  Only changed dotted paths are sent, `null` means delete, and host-owned keys (`sessionQueue*`) are never written back.
- **Collections use command semantics plus revision broadcasts.** List/pin/ungroup/collapse fields are applied
  server-side inside the prefs file lock via `add`/`remove`, so two tabs adding an item no longer lose one of them.
  After a successful write the server broadcasts the changed keys over the existing running-events SSE stream
  (no extra connection): sub-second sync within one backend, with the existing focus-refresh as fallback.
- **Unread is now cross-device.** The server records `completedAt` when a run finishes (even with no browser open) and
  each client records `readAt` when opening a session; unread ⟺ `completedAt > readAt`. Both sides use monotonic
  timestamps merged by union, so no CAS is needed. The local copy is only a first-paint cache.
- **Scopes are pinned down.** Window preferences (footer, guide target) and file-tree expansion/scroll are local-only;
  plugin/skill locks are written per key; the device registry takes a cross-process lock; `docs/architecture.md` gains
  a state-scope/conflict-rule table with the invariants.

### Sidebar

- **New "ungrouped sessions" section** for sessions whose directory is not a project (closed projects, never-added
  directories); re-adding a project does not move them back. Search hits, the archive view, recent and pinned areas
  no longer filter by project.
- **The list no longer stays empty forever**: `/api/sessions` gets a 10s timeout and up to two bounded retries.
- Migration no longer seeds the shared project list from recent session directories.

### Chat, files, extension panels

- Returning to the foreground recovers once (focus + visibilitychange coalesced).
- Window-title ownership moved to AppShell; extension `setTitle` is a temporary override with a TTL.
- Opening a file fetches its diff immediately, so the per-file "Git diff" toggle appears right away.
- Extension select dialogs: no redundant "Close" next to "Cancel", long questions scroll, and an expand/collapse
  toggle that defaults to expanded.

### Subagents

- The async-subagent panel renders TUI-style rows (no raw machine payload) without terminal key hints.

### Desktop shell (Electron)

- **The tray settings entry and desktop notifications are wired up**: the tray's "Desktop settings" opens the new
  Desktop page in Settings, where start-at-login / minimize-to-tray / desktop notifications are read and written
  through the preload bridge; a finished session raises a system notification while the window is in the background.

### Test infrastructure

- Browser regression runs each case in its own browser session; the main suite is green three runs in a row.
  The unread cross-device case (flaky on loaded machines) moved to `npm run test:browser:unread`.
- New direct tests for the cross-process lease (peer holding the lease ⇒ `ensureLive`/`submitPrompt`/offline writes
  all fail with 409 and **not a single byte is written**), a gate that `?wake=1` is only used by the send handshake,
  and a gate that "locked" is classified in exactly one place.

### Known limitations

- The unread cross-device browser case can fail on a heavily loaded machine (browser-side connection starvation);
  the timeout+retry keeps the user-visible sidebar from staying empty, but the case itself may still go red.
- Concurrent additions to the same array are now safe through command semantics, but writing a collection with a
  patch (e.g. hand-written API calls) still replaces it wholesale — see `docs/architecture.md`.
- The real Electron smoke test only runs in CI (Windows); `desktop/` dependencies are not installed locally, so the
  page side is verified with an injected mock bridge.
