# v0.2.38

## 中文

本版以**扩展兼容**为主：把「插件在原生 TUI 里画得出来的东西」在 Web 上补齐，逐条按 `docs/extension-compat-gaps.md` 的清单收口。

### 扩展接口：一批"看起来在跑、其实没接线"的地方

- **渲染桥原本是死的**：宿主一直在监听 `tool_call` / `tool_result`，而 SDK 只在**扩展 runner** 上发这两个
  事件，会话事件流里只有 `tool_execution_start/update/end`。于是插件的 `renderCall` / `renderResult`
  **从来没被调用过** —— 内置 edit 的 diff 预览、bash 的耗时、插件自己的 spinner 全都没有落点。
  现在改接真实事件，并加了同键不并发、100ms 限频、未变帧不推。
- **edit 的 diff 仍然画不出来**，因为 SDK 的 `renderDiff` 读的是 SDK 全局主题单例，我们只建了自己的
  Theme、从没初始化那个槽位，异常被渲染桥的 try/catch 吞掉。现在把同一个 Theme 实例写进 SDK 的全局
  槽位；这类**宿主自身配置错误**给一次可见警告，插件自己的渲染器出错仍旧静默降级。
- **`terminal.rows` 一直是常量 40**（`columns` 早已是前端上报的真实值），插件按它裁布局就会**裁掉内容**。
  现在按会话上报真实视口行数，行数抖动带宽 ±1。
- **`theme` 不是真 Theme**：之前用 Proxy 把未知成员包成可调用函数，`if (theme.sourcePath)` 之类会误判。
  现在直接给真 Theme（`fg` 遇到未知颜色会抛，与 SDK 一致），插件上色输出真 ANSI。
- **`getEditorText()` 一直在撒谎**（恒返回空串），而 pi-subagents 的 fleet 激活守卫就是 `=== ""`。
  现在读客户端**本来就会**同步到服务端的草稿镜像，**零新增打字往返**；代价是滞后一次 PUT，
  边界已写进文档。
- **`getEditorComponent()` 断链**：`setEditorComponent` 成功后取回来仍是 `undefined`，「包一层再设回去」
  的写法无处落脚。现在如实回传上次配置的工厂。
- **`onTerminalInput` 的覆盖范围**现在注册时明确告知（两个窄窗口逐字写明），而且**这条提示本身可水合**
  —— 否则扩展加载发生在浏览器订阅之前，提示永远看不到。提示按 id 认领，**关掉之后不会再回来**。
- 其余：`tui.focusedComponent` 注入（配合按键路由窄口子，pi-subagents 的 roster 可用）、
  工具显示名 `label`、`renderShell: "self"` 不再套我们的卡片外壳、命令参数补全
  （`/mcp <Tab>` 那种）、`setToolsExpanded` 界面跟随、overlay `hide()` 按 pi-tui 契约做成永久移除、
  `setTitle` 不再 30 秒后静默回落（并按**会话键**作废，同项目两个会话不再串）。
- **插件的自定义 entry 与自定义消息**在时间线里都有落点（以前是整段消失或退回原文）。

### 派发给扩展的事件不再被绕过

- 树导航（精确切 leaf / 从某条回复建分支）以前自己改 JSONL 和 leaf，**不派发** `session_before_tree`
  （可取消）与 `session_tree`，维护分支索引或要 veto 的插件在 Pidance 里看不到动作。现在按顺序派发：
  before（可取消，取消即零改动）→ 用本会话的 writer 落地 → tree → 再交出 writer。
- 顺带修掉一个把 Pi 的**并发闸门**丢掉的实现问题（导航期间本应表现为"压缩中"，从而挡住新 prompt 与
  第二次导航），以及事件目标用错 id（记的是 assistant、落地却是轮末）。

### 流式与退出

- **退出时先 dispose 再切流**：以前只 `server.close()` 然后 8 秒强退，在途的 JSONL/SSE 写入会被截断，
  租约也收不干净。
- **连接首帧带快照**：冷挂载或重连进入运行中的会话时，不再吞掉早到的部分文本与正在跑的工具。
- 断流期间产生的**工具渲染行**会随快照回放（同一 `toolCallId` 的整帧替换语义）。

### 长会话

- 上下文尾部按**用户可见消息**计数（以前数 `toolResults`，工具密集的会话首屏只显示 1–5 轮）。
- 只读会话管理器指纹缓存（含 leaf sidecar），目录扫描走 `allowStale`，而路径定位与权限判定仍走新鲜路径。
- 全量会话扫描不再接受项目目录里指向会话根之外的符号链接，与有界定位同口径。

### 会话、侧栏与多标签

- **对端抢锁后锁定条几秒内出现**（以前要等一次状态刷新，空闲时最长 2 分钟）：新增只读的锁探测，
  仅在未锁且可见时轮询。
- **每个标签页记着自己上次在看的会话**（`sessionStorage`，不是 `localStorage`——后者会让一个窗口把
  其它窗口拖到自己的会话）。地址栏的 `?session=` 仍是权威；记住的会话若已失效就清掉并按裸地址走，
  不会停在"会话未找到"。
- 回复下方列出**本轮写入的文件**，并可一键把路径引用进输入框。

### 客户端渲染

- 折叠行统一规则：流式中显示末尾行，流式结束显示首行（工具块的首行是命令行）；思考块展开不再限高，
  工具卡展开后不再重复显示同一段输出。
- 截断提示（`stopReason: length`）、`apply_patch` 的拆分 diff 与失败列表、搜索命中跳转、视频预览。
- 隐藏标签超过 5 分钟关闭 SSE（回前台走既有重连与对账）。

### 连接卫生与失败恢复

- **`pagehide` 时显式关闭长期连接**：这修掉了"同一标签页连续两次导航后聊天区挂不上"——
  上一个文档残留的连接占着同源预算，新页面的早期请求被饿住、各自超时，页面停在半初始化状态。
- 加载失败改为**有界重试**（带退避），仍失败时给**可见且可点重试**，不再只留一行 `TimeoutError`。

### 安全与数据正确性

- **升到 Next.js 16.3.6** 并设 `images.unoptimized`（本仓库不用 `next/image`/`next/og`，零成本），
  覆盖 AVIF 解析、Windows 文件系统未授权 RCE 等 advisory（我们发布 Windows 桌面壳，后者没有 workaround）。
- 同源 `undici` 一并升到 8.11.0。**注意行为变化**：经 HTTP 代理访问 **http（非 TLS）**目标时改为向代理
  发绝对 URI 请求，https 目标仍是 CONNECT 隧道。
- **文件流加 `X-Content-Type-Options: nosniff` 与 SVG 的 `default-src 'none'` CSP**：以前用 `?type=read`
  打开一个仓库里的 SVG，脚本会在应用源内执行，能带着凭据访问所有 `/api`。
- **`models.json` 读失败不再被覆盖写**（GET 422 / PUT 409），此前一次解析失败会退化成空配置，
  再保存就把所有 provider 和 apiKey 抹掉。
- **密码不再留在 agent 的 bash 环境里**：`PI_WEB_PASSWORD` / `PIDANCE_PASSWORD` 在启动时读入内存后被删除，
  并在 Next 重新加载 `.env*` 之后再擦一次（否则会被写回去）；WebSocket 升级路径同样鉴权。
- **认证限流**：Basic 与登录表单共用同一套计数器与指数退避，身份取对端地址而不再信任 `x-forwarded-for`;
  反向代理场景有显式开关（默认关，宁可误伤也不放过）。
- 会话 Cookie `SameSite=Strict` → `Lax`（手机从外部应用顶层导航进来不再丢登录态，CSRF 仍由
  origin/`sec-fetch-site` 校验保证）；OAuth 挂起 token 由 `Math.random` 改为 `crypto.randomUUID`。

### 模型管理

- 扩展注册的 provider 会出现在供应商列表里；每个模型可单独启用/禁用（**最小范围改写**
  `settings.json` 的 `enabledModels`，不动其它键）；「刷新模型目录」端到端生效。

## English

This release is mostly about **extension compatibility**: making what a plugin can draw in the native TUI
actually land on the Web, working down `docs/extension-compat-gaps.md`.

### Extension surface: things that looked wired but were not

- **The render bridge was dead.** The host listened for `tool_call` / `tool_result`, but the SDK only emits
  those on the *extension runner*; the session stream carries `tool_execution_start/update/end`. So plugin
  `renderCall` / `renderResult` **were never called** — the built-in edit diff preview, bash elapsed time and
  plugin spinners had no landing point. Now wired to the real events, with per-key serialisation, a 100 ms rate
  limit and unchanged-frame suppression.
- **The edit diff still did not render**, because the SDK's `renderDiff` reads the SDK global theme singleton and
  we only built our own theme. The exception was swallowed. We now publish the same theme instance into that
  slot; host-side misconfiguration warns **once**, plugin renderer errors still degrade silently.
- **`terminal.rows` was the constant 40** (while `columns` was already the real reported value), so plugins
  cropped their layout by a wrong row count — **cropped rows were simply absent**. Rows are now reported per
  session, with a ±1 stability band.
- **`theme` was not a real Theme**: unknown members were wrapped in a callable Proxy, so `if (theme.sourcePath)`
  misjudged. Plugins now get the real Theme (unknown colours throw, matching the SDK) and their colour output
  is real ANSI.
- **`getEditorText()` always lied** (empty string) while pi-subagents' activation guard is `=== ""`. It now reads
  the composer draft the client already mirrors to the server — **no extra round trip** — at the cost of one PUT
  of lag, documented including its edge cases.
- **`getEditorComponent()`** returns the last configured factory instead of always `undefined`.
- **`onTerminalInput` coverage** is announced once at registration (both windows spelled out), and **that notice
  itself hydrates** — previously extension loading happened before the browser subscribed, so the notice was
  lost forever. Notices are claimed by id, so **dismissing one sticks**.
- Also: `tui.focusedComponent` injection (with a narrow key-routing channel, so pi-subagents' roster works),
  tool display `label`, `renderShell: "self"` no longer wrapped in our card shell, command argument completion,
  `setToolsExpanded` reflected in the UI, overlay `hide()` made a permanent removal per the pi-tui contract, and
  `setTitle` no longer silently reverting after 30 s (and keyed per session).
- **Plugin custom entries and custom messages** now have a landing point in the timeline.

### Tree navigation dispatches extension events

- Tree navigation (exact leaf switch / branch from a reply) rewrote the JSONL and leaf itself, **skipping**
  `session_before_tree` (cancelable) and `session_tree`. Now: before (cancelable, cancel changes nothing) →
  land with this session's writer → tree → hand the writer over.
- Along the way: a lost Pi concurrency gate (navigation should present as "compacting" so new prompts and a
  second navigation are refused) and an event target using the assistant id while the leaf landed on turn end.

### Streaming and shutdown

- **Dispose before cutting streams on exit** (previously `server.close()` then a forced exit 8 s later could
  truncate in-flight writes and leave leases behind).
- **First-frame snapshot on connect**, so a cold mount or reconnect into a running session no longer swallows
  early partial text or running tools. Buffered tool render lines are replayed too.

### Long sessions

- The context tail is counted by **user-visible messages** (it used to count `toolResults`, so tool-heavy
  sessions showed only 1-5 turns on the first screen).
- Read-only session-manager fingerprint cache (including the leaf sidecar), `allowStale` for directory scans,
  while path resolution and permission checks stay on the fresh path.
- The full session scan no longer accepts symlinked `.jsonl` files escaping the sessions root.

### Sessions, sidebar, multi-tab

- **A foreign writer lease shows its lock bar within seconds** (it used to wait for a state refresh, up to
  2 minutes when idle).
- **Each tab remembers the session it was viewing** (`sessionStorage`, not `localStorage`). The URL parameter
  still wins; a remembered session that no longer exists is dropped, not shown as an error screen.
- A **files written this turn** card under the reply, with one-click path reference into the composer.

### Client rendering

- Unified collapsed-row rule: last line while streaming, first line once streaming ends (the command line for
  tool blocks); expanded thinking blocks are no longer height-limited; expanded tool cards no longer show the
  same output twice.
- Truncation notice, split `apply_patch` diff with per-file failures, search-hit jumping, video preview.
- Hidden tabs close their SSE after 5 minutes.

### Connection hygiene and failure recovery

- **Explicitly closing long-lived connections on `pagehide`** fixed "chat area fails to mount after two
  consecutive navigations": the previous document's leftover connections held the same-origin budget, the new
  page's early requests starved, each timed out, and the app stayed half-initialised.
- Load failures now **retry boundedly** and then offer a **visible retry** instead of a bare `TimeoutError`.

### Security and data correctness

- **Next.js 16.3.6** with `images.unoptimized` (no `next/image`/`next/og` here), covering the AVIF parsing and
  unauthenticated Windows filesystem RCE advisories (we ship a Windows desktop shell; the latter has no
  workaround). `undici` bumped to 8.11.0 — note the behaviour change for **http (non-TLS)** targets behind an
  HTTP proxy (absolute-URI requests instead of CONNECT tunnels; https still tunnnels).
- **`nosniff` and a `default-src 'none'` CSP for SVG** on the file stream: opening a repository SVG used to
  execute scripts in the app origin with credentials.
- **A failed `models.json` read is no longer overwritten** (GET 422 / PUT 409) instead of degrading to an empty
  config and wiping every provider and API key on the next save.
- **The password no longer stays in the agent's bash environment** (`PI_WEB_PASSWORD` / `PIDANCE_PASSWORD` are
  read into memory at start and deleted, then scrubbed again after Next reloads `.env*`); WebSocket upgrades are
  authenticated too.
- **Auth rate limiting**: one shared exponential backoff for Basic and the login form, keyed on the peer address
  rather than a spoofable `x-forwarded-for`, with an explicit reverse-proxy switch (off by default).
- Session cookie `SameSite=Strict` → `Lax` (no more lost login when arriving from an external app on mobile);
  OAuth pending tokens use `crypto.randomUUID`.

### Model management

- Extension-registered providers appear in the provider list; per-model enable/disable via minimal-range edits to
  `enabledModels`; "refresh model catalog" now works end to end.
