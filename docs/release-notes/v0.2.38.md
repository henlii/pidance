# v0.2.38（未发布）

本版**没有发布到 npm**。它的 tag `v0.2.38` 已推送，但 release workflow 在 Next 生成的路由类型检查处失败：

```
.next/types/app/api/auth/all-providers/route.ts: error TS2344:
Property 'createAllProvidersHandler' is incompatible with index signature.
```

route 文件里导出了供测试注入的工厂函数，而 Next 只允许 route 导出 HTTP 方法；本地 `tsc --noEmit` 覆盖不到
`next build` 生成的路由类型，所以当时没被拦住。按发布口径不移动已推送的 tag，修复后改用
[v0.2.39](v0.2.39.md) 发布，其变更清单与本版相同。
