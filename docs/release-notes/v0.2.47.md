# v0.2.47

## 中文

包名 `@henlii/pidance`，CLI 仅 `pidance`。

### 会话统计改为全量，右上角统计变气泡弹窗

统计数字以前由前端按**当前加载的窗口**求和，长会话与压缩过的会话都会偏小。现在由服务端扫描
折叠整条 JSONL（与 dsh 的 whole-log projection 同口径，随列表扫描缓存按 mtime/size 失效），
新增 `GET /api/sessions/[id]/stats`；右上角点击改为气泡弹窗——上半是本轮读数（输出速度、
平均首字延迟、模型用时、工具调用用时、步骤、输出词元），下半是会话累计词元（缓存命中、
输入、缓存读写、输出、总计、上下文、用户与工具调用数）。会话内容懒加载不影响这些数字。

同时修掉吞吐口径的一个回归：工具结果消息（`role: toolResult`）不再被当成本步的「首 token」。
以前它会让分母从工具结束那一刻起算，把重新请求的等待算进解码时间——工具调用越多读数越低。

### 插件面板：全屏面板 / 半屏面板

面板不再覆盖会话区，改成会话列里的布局块：

- **全屏面板**（`ctx.ui.custom()` 未声明 overlayOptions）：位于标题栏与会话区之间，展开时替代
  会话区，收起时只留一行标题并把会话区还回来；
- **半屏面板**（带 overlayOptions）与**阻塞弹窗**：位于会话区之下，展开时占会话区高度的一半；
- 三者任一激活时，输入区（todo / 输入框 / footer / widget）整体隐藏；
- 去掉遮罩（面板与会话区同屏，不需要分层）；插件声明的宽度差异保留。

底栏重排：方向键 / 回车 / Esc 那排控制键从「固定在屏幕底部、只在手机显示」移到**面板底栏左侧**，
其后是渲染控制（复制），右侧是取消 / 提交。「切回原样」暂时隐藏——行级语义识别对多数面板看不出
差别，按钮留着只会让人以为没生效；能力仍在（`rawMode` / `onToggleRawMode` 保留），随时可放回。

### 多实例：锁状态与会话列表即时同步

31415 与 31416 打开同一会话时：打开仍然只读、不抢锁；一方开始执行后，另一方的锁定状态与会话
列表**即时更新**（`fs.watch` 盯租约目录与会话目录 → 应用级 SSE 推 locks / sessions-changed），
另有 2 秒（锁）与 5 秒（列表）兜底对账，应对 inotify 在容器挂载/网络盘上静默失效。锁的判据是
「对端进程还活着」，与 `acquireRunningLease` 同口径——心跳过期但进程存活时仍算被占用，
不会推一个空锁集把锁定条误收起来。

对端删掉你正打开着的会话时，界面自动切回引导页（判据是「上一次列表里还有、这一次没有了」，
冷启动时 `?session=` 指向不存在的会话仍走既有的错误态）。

### 思考档位：磁盘权威 + 运行中禁改

会话档位以**磁盘落地值**为权威（Pi 的热状态历史上会把 max/xhigh 报成 high，不让热状态覆盖已
落地的值）。另外**运行中不允许修改模型与思考深度**：按钮禁用 + 事件门禁双保险，避免界面显示的
档位与实际发请求的档位分叉（文案是「运行中不能修改模型或思考深度」）。

### 手机查看图片支持双指缩放

图片查看器新增捏合缩放：按两指间距的**比例**变倍（不是绝对位移），夹在 1×–8×；松开一根手指
退出手势；捏合过之后不会被误当成「点背景关闭」。算术抽成纯函数 `pinchZoom()` 并有单测覆盖。

### 输入框高度交给浏览器

textarea 改用 `field-sizing: content`（支持的浏览器零 JS 参与），不再每次按键读 `scrollHeight`
触发强制重排；不支持的浏览器保留原有 JS 回退。

**已知问题**：输入框每键约有 15ms 的渲染开销。实测与文本长度关系不大（1k→50k 字符：16ms→19ms），
来自每键重渲染输入区子树；本次只做了小幅优化（5000 字符从 17.3ms 降到 15.4ms），彻底解决需要
重构输入区的渲染结构。

### 验收范围

`tsc --noEmit`、`npm test`（2771 项）、31416 无头浏览器实测：三种面板形态的位置与高度、
面板底栏控制键顺序、跨进程 locks / sessions-changed 帧、对端删除后切引导页、运行中模型按钮禁用、
统计弹窗数值与全量口径一致、图片查看器捏合算术单测。

## English

Package `@henlii/pidance`, CLI `pidance` only.

### Session stats are whole-log now; the top-right readout is a popover

Totals used to be summed by the client over the **currently loaded window**, so long or compacted
sessions under-reported. The server now folds the entire JSONL (same shape as dsh's whole-log
projection, cached by mtime/size) behind `GET /api/sessions/[id]/stats`, and the top-right readout
opens a popover: this run's speed and timing on top (output speed, average first token, model time,
tool time, steps, output tokens), session-wide token usage below.

The same change fixes a throughput regression: a tool-result message is no longer mistaken for the
step's first token — it used to start the decode window at tool completion, lowering the reading the
more tools a turn called.

### Plugin panels: full-screen panel / half-screen panel

Panels are layout blocks in the conversation column instead of overlays:

- **full-screen panel** (`ctx.ui.custom()` without overlayOptions): between the title bar and the
  conversation area; expanded it replaces the conversation, collapsed it keeps one row;
- **half-screen panel** (with overlayOptions) and **blocking dialogs**: below the conversation area,
  expanded they take half of its height;
- while any of them is active the composer area (todo, input, footer, widgets) is hidden;
- the scrim is gone (panel and conversation share the screen); plugin-declared widths are preserved.

The footer was reordered: the arrow keys / Enter / Esc control keys moved from a bottom-fixed bar
(mobile only) into the panel footer's left side, followed by render controls (copy) on the left and
cancel/submit on the right. "Back to raw" is hidden for now — line-level semantic recognition looks
identical on most panels, so the button only raised questions; the capability is still there.

### Multi-instance: live lock and session-list sync

Opening a session stays read-only and lock-free; once one instance starts executing, the other's lock
state and session list update immediately (`fs.watch` on the lease and session directories feeding the
app-level SSE), with 2s/5s fallback reconciliation. The lock predicate is "the other process is alive",
matching `acquireRunningLease` — an expired heartbeat on a live process still counts as locked.

If the other instance deletes the session you have open, the UI returns to the guide page.

### Thinking level: disk is authoritative, and it is read-only while running

The session's thinking level follows the value landed on disk (Pi's live state has historically
reported max/xhigh as high). Model and thinking level can no longer be changed **while a run is in
progress** (buttons disabled plus an event-level guard).

### Pinch-to-zoom for images

The image viewer gains pinch zoom: scale is proportional to finger distance, clamped to 1x-8x,
releasing one finger ends the gesture, and a pinch never counts as a backdrop tap. The arithmetic
lives in a pure `pinchZoom()` with unit tests.

### Textarea height is the browser's job

The composer textarea uses `field-sizing: content` where supported (no JS per keystroke, no forced
reflow), with the previous JS fallback elsewhere.

**Known issue**: typing still costs about 15ms per keystroke, roughly independent of text length
(1k→50k chars: 16ms→19ms). It comes from re-rendering the composer subtree on every keystroke;
this release only shaves it slightly (5000 chars: 17.3ms→15.4ms). A real fix needs a rendering
restructure of the composer.
