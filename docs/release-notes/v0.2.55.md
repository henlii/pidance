# v0.2.55

## 中文

包名 `@henlii/pidance`，CLI 仅 `pidance`。

### 一、内核升到 1.1.0（对齐与接线，不做功能替换）

内核从 0.87.0 一步升到 1.1.0（`@earendil-works/pi-coding-agent` 与 `pi-tui` 同版本），
补齐了新内核要求的字段与我们已经漏掉的能力：主题里的 `okhsl()/oklch()` 语法、工具渲染上下文的
`outputPad`（缺了会让内置 edit 卡片排版坏掉）、`durationMs`、嵌套工具调用
（`parentToolCallId`，此前会把子调用画成多余卡片）、扩展加载告警（不再只留在服务端日志）、
`quietStartup` 的第三种取值不再被保存时抹掉、Azure 新 provider id 双认。

内核自带的扩展（codemode / tool-search / mcp）也接上了，但 MCP 流量仍走插件
`pi-mcp-adapter`（它注册了 `/mcp` 命令，按名字顶掉内置那份），所以行为不变、只是内核能力可用。
`get_tools` 现在也回工具的 exposure 与注解（readOnly / destructive / idempotent / openWorld）。

### 二、后台跑完切回来不刷新

页面在后台时 run 结束，切回来会话内容不刷新（要手动刷新）。根因是回前台那次重拉是**一次性的、
不看结果**：磁盘页可能被判为过期而丢掉。现在回前台会检查尾部有没有变，没补到就在 800ms 后
再补一次（正常情况零额外请求），另外补上 `resume` 监听与详情请求的 `cache: 'no-store'`。

### 三、面板高度

手机端扩展面板一显示就开始被压，最后只剩一行问题。根因是插件量到的「终端尺寸」来自面板正文，
而正文高度由内容决定 —— 是个自反馈环。现在改用整个会话列当宿主（宽度也顺手对了，之前右边框被裁）。

### 四、输入框与命令

按 ↑/↓ 在输入框里取回历史消息（对齐终端里的肌肉记忆，首次按 ↑ 会先把当前草稿存起来）。
斜杠命令面板补齐到「TUI 内置命令里有 Web 落点」的那一档（设置/模型/档位/新会话/恢复/树/导出等），
终端专有命令（`/quit`、`/hotkeys` 等）给明确的不支持理由，不再被当成普通消息发给模型。

### 五、模型与档位：两处「界面在骗人」

- **切了模型又被写回默认**：SDK 建会话时 `leafId` 还没恢复，模型与档位会落到 `settings.json`
  的默认值**并被写进会话文件**，于是「切了模型，改一下档位又变回去」。现在建会话后按磁盘的
  权威值把模型拉回来，且只在当前值等于默认值时才动手（不会覆盖用户刚下的命令）。
- **档位被夹住却报成功**：模型不支持的档位会被 SDK 夹到它能支持的那个，而且不写盘、不报错。
  请求 `max`、模型只到 `xhigh` 时，界面过去一边说「已切到 max」一边还是 `xhigh`。现在 host
  回生效档位，界面如实说「该模型不支持档位 max，已改为 xhigh」。

### 六、其它

图片附件也把**原图路径**注入消息（此前智能体只能自己去附件目录里猜文件名）；「隐藏思考块」
设置终于生效（此前写了没人读）；模型 chip 后面显示虚拟模型「→ 实际派发的模型」；子代理异步面板
一变就补一次运行数据（此前要等最长 30 秒的轮询，导致下拉里看不到正在跑的那个）。

桌面壳本轮不发（用户决定暂时停更），因此不改 `desktop/` 的版本与 lockfile。

### 验收范围

`tsc --noEmit`；eslint 0 error；`npm test` 2863 项；31416 实测：切模型后改档位不再退回默认模型、
档位被夹住时如实提示、后台冻结标签页解冻后无需刷新即出现回复、手机视口下面板高度稳定、
输入框 ↑/↓ 取回历史、斜杠命令面板描述为中文且无 key 名残留。

## English

Package `@henlii/pidance`, CLI `pidance` only.

### 1. Kernel upgraded to 1.1.0 (alignment and wiring, no feature replacement)

The kernel moved from 0.87.0 to 1.1.0 in one step (`@earendil-works/pi-coding-agent` and `pi-tui`
pinned to the same version), with the fields the new kernel requires and the capabilities we had
missed: `okhsl()/oklch()` theme syntax, the tool render context's `outputPad` (its absence breaks the
built-in edit card layout), `durationMs`, nested tool calls (`parentToolCallId`, previously drawn as
extra cards), extension load warnings (no longer confined to the server log), the third
`quietStartup` value (no longer erased on save) and dual recognition of Azure's new provider id.

The kernel's own extensions (codemode / tool-search / mcp) are wired up, while MCP traffic still goes
through the `pi-mcp-adapter` plugin (it registers `/mcp`, which replaces the built-in by name), so
behaviour is unchanged. `get_tools` now also reports tool exposure and annotations.

### 2. Returning to a backgrounded page no longer needs a refresh

The return-to-foreground reload used to be a single, unchecked request, so a disk page judged stale
was silently dropped. It now checks whether the tail moved and retries once after 800 ms, plus a
`resume` listener and `cache: 'no-store'` on the session detail request.

### 3. Panel height on phones

The plugin's terminal size was measured from the panel body, whose height depends on the content it
draws — a feedback loop that shrank the panel to one line. The host is now the whole session column.

### 4. Composer and commands

Up/Down recalls input history (with the current draft stashed on the first press). The slash-command
palette now covers every TUI built-in that has a web landing point, and terminal-only commands
(`/quit`, `/hotkeys`, ...) are refused with a reason instead of being sent to the model as text.

### 5. Models and thinking level: two places where the UI lied

- **A model switch was written back to the default**: when the SDK creates a session the leaf is not
  restored yet, so model and thinking level fall back to `settings.json` defaults *and are written to
  the session file*. The host now restores the model from the file's authoritative value after
  creating the runtime, and only when the current value equals the default (so a command the user
  just issued is never overwritten).
- **A clamped thinking level reported success**: the SDK clamps unsupported levels and silently
  writes nothing. Asking for `max` on a model that tops out at `xhigh` used to show "switched to
  max" while staying at `xhigh`; the host now returns the effective level and the UI says so.

### 6. Others

Image attachments now inject the **original file path** into the message; the "hide thinking blocks"
setting finally works (it used to be written and never read); the model chip shows the virtual
model's routed target; the async subagent panel refreshes run data as soon as it changes (previously
up to a 30-second poll delay, so a running subagent was missing from the dropdown).

The desktop shell is not released this time (frozen by user decision), so `desktop/` versions and
lockfiles are untouched.

### Verification

`tsc --noEmit`; eslint 0 errors; `npm test` 2863 tests; measured on 31416: a model switch survives a
thinking-level change, a clamped level is reported honestly, a frozen tab shows the reply without a
refresh, the panel keeps a stable height at phone width, Up/Down recalls history, and the slash
palette renders localised descriptions.
