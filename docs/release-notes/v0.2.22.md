# v0.2.22

## 中文

### 聊天内容可以正常选中复制
- **修根**：聊天页面此前每帧全量重渲染，代码块/表格/工具输出节点每秒被重建上千次，拖选进行中的选区随节点替换被清掉——这是「表格/代码/特殊块全部选不中」的真正原因。
- MarkdownBody 现已 memo 化：消息文本未变就跳过重新渲染，已完成的消息 DOM 稳定，拖选/长按选区在松手后保留。
- 表格滚动层与边框层分离；表格、代码、diff 显式允许文本选择，行号仍不可选。

### 其它
- 按下鼠标即暂停自动跟随（此前依赖 selectstart，部分块不触发），不再把选区滚掉。
- 桌面壳内置服务同步至 0.2.21（本包）。

## English

### Chat text is selectable again
- **Root cause fixed**: the chat tree re-rendered every frame and ReactMarkdown rebuilt every code/table node each pass (~2k node swaps/s), tearing down any in-progress selection on tables, code, and diffs.
- MarkdownBody is now memoized: finished messages keep stable DOM, so drag/long-press selection survives pointerup.
- Table scroll layer split from the rounded border; code/tables/diffs explicitly allow selection while line numbers stay unselectable.

### Other
- Auto-follow releases on pointerdown (selectstart does not fire on every block).
- Bundled service bumped to 0.2.21 (this package).
