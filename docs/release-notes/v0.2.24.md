# v0.2.24

## 中文

### 桌面壳移除与 Linux 服务形态
- 移除 `desktop/` 桌面壳（Electron）与 Windows 安装器发布链（`desktop-win.yml`、`release.yml` 桌面任务）。
- 31415 正式服务回归用户级 systemd unit：一键升级可经 `systemctl --user` 自重启，不再需要 root。
- 31416 测试部署支持以普通用户身份运行并共享 `~/.pi/agent`（安装脚本 `PIDANCE_SERVICE_USER` / `PIDANCE_SECRET_ENV`），与会话/模型/设置同源。

### 草稿删除修复（发送后草稿复活）
- 服务端偏好合并改为显式 null 墓碑删除：发送/清空输入后的草稿不再残留服务端，刷新、切会话或窗口激活后不会再「复活」。

### 会话等待指示（询问用户时）
- 运行中的会话保留原有旋转动画；agent 在询问用户（extension 弹窗/ask 暂停）时，会话列表改为显示与未读点同构的黄色圆点（等待你回复），暂停计时/时长不再显示。

### 思考档位显示竞态
- 模型按钮在会话档位被权威源确认前不显示档位标签；思考档回写事件仅在当前会话已加载后应用，避免「切走再切回后档位显示串台」。

## English

### Desktop shell removal and Linux service shape
- Dropped the `desktop/` Electron shell and the Windows installer pipeline (`desktop-win.yml`, desktop jobs in `release.yml`).
- The official 31415 service is back on a user-scope systemd unit, so one-click upgrades can restart via `systemctl --user` without root.
- The 31416 test deploy can run as a normal user sharing `~/.pi/agent` (installer `PIDANCE_SERVICE_USER` / `PIDANCE_SECRET_ENV`), sharing sessions/models/settings with the official instance.

### Draft deletion fix (draft resurrection after send)
- Server preference merging now deletes keys via explicit null tombstones: sent or cleared drafts no longer linger server-side and resurrect on refresh, session switch, or window refocus.

### Sidebar waiting indicator (while asking you)
- Running sessions keep the spinning animation. When the agent pauses to ask you (extension dialog / ask), the row shows a yellow dot matching the unread dot ("Waiting for you") instead, and the running duration is hidden.

### Thinking-level display races
- The model button hides the level chip until the session's authoritative level is confirmed; thinking-level event writes only apply after the current session has loaded, preventing level cross-talk when switching sessions.
