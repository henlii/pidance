# v0.2.25

## 中文

### 多媒体消息与文件交付
- 支持图片、音频、视频和普通二进制文件消息块。
- 图片消息使用受限尺寸缩略图，点击后在输入框上方打开内联预览，支持缩放、拖动、触屏操作、关闭和下载原图。
- 音频和视频不超过 25 MB 时支持直接播放，超过后仅提供原文件下载。
- 新增内置 `send_file_to_user` 工具。智能体生成文件后可将其作为用户可查看、可下载的消息发送，而不是只输出本地路径或 Base64。
- 文件交付说明注入 Pidance 系统文令；原始附件与 UI 元数据分离保存。

### 大图片上传与交互
- 图片上传改为流式媒体接口，避免大图片 Base64 进入 prompt JSON 导致 JSON 截断。
- 消息内部滚动支持滚轮和触屏继续传递到会话容器。
- follow-up 队列增加折叠/展开控制。
- 扩展阻塞交互改为输入框上方的阻塞式面板，不覆盖会话内容。

## English

### Multimedia messages and file delivery
- Added image, audio, video, and generic binary message blocks.
- Images use constrained thumbnails and open in an inline preview above the composer with zoom, pan, touch gestures, close, and original-file download.
- Audio and video play inline up to 25 MB; larger media is download-only.
- Added the built-in `send_file_to_user` tool so the agent can deliver generated files as user-visible, downloadable messages instead of only printing local paths or Base64.
- File-delivery guidance is injected into the Pidance system prompt, while original attachments remain separate from UI metadata.

### Large-image upload and interaction
- Image uploads use a streaming media endpoint to avoid JSON truncation from large Base64 prompts.
- Nested message scrolling passes wheel and touch input through to the conversation container at its boundaries.
- Added collapse/expand controls for the follow-up queue.
- Extension blocking interactions now use a blocking panel above the composer without covering the conversation.
