# v0.2.23

## 中文

### Windows 桌面版远程访问与升级修复
- 桌面版 31415 不再用固定的 `127.0.0.1` 覆盖服务配置；开启远程访问后，重启桌面版即可按配置监听。
- 修复桌面更新器下载完成回调、GitHub Release 重定向、安装包 `.exe` 扩展名和安装器启动方式。
- 兼容实际的 `Pidance Desktop Setup <version>.exe` Windows 安装器命名。

## English

### Windows desktop remote access and upgrade fixes
- The desktop 31415 service no longer overrides the configured bind address with a fixed `127.0.0.1`; restart the desktop app after enabling remote access.
- Fixed updater download completion, GitHub Release redirects, the installer `.exe` extension, and direct installer launch.
- Accept the actual `Pidance Desktop Setup <version>.exe` Windows installer naming.
