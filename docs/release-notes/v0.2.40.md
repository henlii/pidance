# v0.2.40

## 中文

本版把 **SDK `ExtensionUIContext` 里我们还没实现或只部分实现的成员全部落地**（issue #96–#107，五批），
不再用「可见降级 + 一次提示」代替实现；另有五条与运行/未读/主题相关的正确性修复。

### 扩展 UI 全量对齐

- **思维标签**（#96）：`setHiddenThinkingLabel` 按会话生效，替换**折叠态**思考行的摘要；插件文本原样透传、60 字截断并把全文放进 `title`；`ctx.reload()` 会清掉它。
- **主题**（#97）：改用 SDK 的**真 Theme**（不是自造的类，`instanceof` 与全局槽位都对得上）；内置 dark/light + `~/.pi/agent/themes/*.json`；`getTheme(name)` 只加载不切换、`setTheme` 切换并返回 `{success, error}`；壳的明暗与插件 ANSI 主题**双向联动**（自定义主题名不映射壳，是有意分叉）。
- **页头 / 页脚槽位**（#98）：走与 widget 同一条渲染管线；替换先 dispose；`setFooter(undefined)` 还原我们自己的状态栏；窄视口限高 + 内部滚动；工厂抛错只警告一次并隐藏该槽位。
- **overlay 句柄**（#99）：`focus()` / `unfocus(target?)` / `getBounds()` 真有语义（三态焦点；几何用客户端上报的字符格缓存，同步可读）。
- **对话框超时**（#100）：下发**绝对截止时间**，结算由服务端推送（`extension_ui_settled`），客户端倒计时只读、不再自行关闭面板。
- **插件补全**（#101）：`addAutocompleteProvider` 支持工厂链与 `triggerCharacters`；插件返回**空数组表示"没有候选"**，不回落到我们自己的 `@` 文件补全；每个请求独立 `AbortSignal`；IME 期间不发请求。
- **按键窗口第三档**（#102）：插件面板/overlay/对话框持有键盘时按保留键表路由；**让位判据改成「焦点落在真实控件上」**（不再按标签白名单，否则会抢走侧栏分隔条、谱系树、工具输出的方向键）。
- **widget 鼠标**（#103）：像素→字符格、触摸长按=右键；**滑动不再被当成点击**（那会误触折叠整块）。
- **内联图片**（#104）：渲染期临时打开图片能力（**必须作用于扩展实际使用的那一份 pi-tui**，本机磁盘上有两份）；**先摘图、再过文本上限**（否则一张图会把旁边正文一起判超限丢掉）；分块不完整就降级为可见说明，绝不出半张图；客户端画真 `<img>` 并带 `alt`。
- **插件快捷键**（#105）：走 SDK 自己的键位解析与冲突矩阵；设置里列出插件快捷键与**不可绑定原因**；不自动改键。
- **Markdown 转换器**（#106）：在渲染边界（分页投影 + 流式帧）施加，转换器抛错保留原文。**不接 SDK 的 mermaid 转换器** —— 它会把 ```mermaid 围栏换成终端 ASCII 图，摧毁客户端的真图渲染。
- **编辑器接管**（#107）：`setEditorComponent` 的组件在输入框位置渲染、按键进 `handleInput`、`onSubmit` 走现有发送管线（失败/早退把正文交回组件）；壳外单独「返回输入框」按钮（**不用 Esc**）；手机与设置关闭时不接管；提交归属按标签 `clientId` 判定，保证**恰好一次**。
- `tui.stop()/start()`（让出真终端）**判定不做**：`stop()` 不带命令、插件自己 `spawn({stdio:"inherit"})`，那个子进程不在我们的终端面板里；唯一能做的是劫持 `spawn`，那是新增信任面。

### 正确性修复

- **切主题后已投影的消息行仍是旧色**（#109）：改成按 entryId 只替换 `renderedLines`（不再走 tail 归并——它换不掉已加载的更早页，还会把历史跳读窗口整段换成尾页）。换色记忆按**内容**判定新旧，内容真变了就让磁盘赢。
- **页面先开、插件后注册要等投影/刷新**（#110）：两条状态应用路径收敛成一处（`applyExtensionUiProjection`，新增字段不会再被某条路径漏掉）；未 live 时按 1.5s 短重试而不是抢连事件流（否则会把 15s 兜底对账降成 120s，比修之前更慢）。
- **侧栏把「host 启动中」算成运行中**（#111）：徽标/计时/列表/SSE 只算「真的在跑」，点开一个空闲会话不再闪出约 2.5 秒的运行标记。
- **PTY 生命周期**（#81）：父进程被 SIGKILL 后 worker 与 shell 不再变孤儿（父进程看护）；Windows 上不再给 node-pty 传 signal（那会在真正清理前抛错，等于不清理）；win32 关终端改成先请 worker 自己退出、超时才强杀；连接加 ping/pong 心跳兜住半开连接。
- **未读死条目**（#95）：回收改成在 prefs 锁内按**最新**桶决定删谁（不再用锁外快照整桶覆盖，避免吃掉扫描期间的并发写入）；会话目录读失败/为空时**放弃本轮不写盘**。
- **浏览器测试注入通道**（#94）：`network route --body` 拦不到页面 fetch，换成导航前注入的 init script 包装 `window.fetch`（只拦 GET，PUT 照走服务端，#62 的泄漏检测仍有效）。

## English

This release lands **every remaining member of the SDK's `ExtensionUIContext`** (issues #96–#107, five batches),
replacing "visible degradation + a one-time notice" with real implementations, plus five correctness fixes around
run state, unread bookkeeping and theming.

- **Hidden thinking label** (#96): per-session, replaces the *collapsed* thinking row, verbatim plugin text, 60-char truncation with the full text in `title`; cleared on `ctx.reload()`.
- **Themes** (#97): the SDK's real `Theme` (so `instanceof` and the global slot line up), built-in dark/light plus `~/.pi/agent/themes/*.json`, `getTheme` loads without switching, `setTheme` switches and reports `{success, error}`, and the shell's light/dark is coupled with the plugin ANSI theme in both directions (custom theme names deliberately stay plugin-side).
- **Header/footer slots** (#98): same pipeline as widgets, dispose-before-replace, `setFooter(undefined)` restores our own status bar, height-capped with inner scroll, a throwing factory hides that slot after one warning.
- **Overlay handle** (#99): `focus()` / `unfocus(target?)` / `getBounds()` with real semantics (three-state focus; synchronous character-cell geometry from a client-reported cache).
- **Dialog timeout** (#100): an absolute deadline is sent down and settlement is pushed by the server (`extension_ui_settled`); the client countdown is read-only and never closes the panel itself.
- **Plugin completions** (#101): `addAutocompleteProvider` with the wrapper chain and `triggerCharacters`; an empty array from a plugin means "no candidates" and does **not** fall back to our `@` file completion; per-request `AbortSignal`; no requests while composing.
- **Third key window** (#102): while a plugin panel/overlay/dialog owns the keyboard, keys follow the reserved-key table; **yielding is now decided by "focus sits on a real control"** instead of a tag whitelist (which used to steal arrow keys from sidebar resizers, the lineage tree and tool output).
- **Widget mouse** (#103): pixel→cell conversion, long-press as right click, and a swipe is no longer treated as a click.
- **Inline images** (#104): the image capability is enabled around the render (against **the pi-tui copy extensions actually use** — two exist on disk), images are extracted **before** the text caps, incomplete chunking degrades to a visible note instead of half an image, and the client renders real `<img>` with `alt`.
- **Plugin shortcuts** (#105): uses the SDK's own parsing and conflict matrix, lists plugin shortcuts and their binding failures in settings, and never remaps keys silently.
- **Markdown transformers** (#106): applied at the render boundary (paged projection plus streaming frames), a throwing transformer keeps the original. The SDK's mermaid transformer is deliberately **not** chained — it would replace ```mermaid fences with terminal ASCII and destroy the client's real diagram rendering.
- **Editor takeover** (#107): the component renders in the composer's place, keys reach `handleInput`, `onSubmit` goes through the existing send pipeline (failures/early exits hand the text back to the component), a separate "Back to input box" button (never Esc), no takeover on phones or when disabled, and per-tab `clientId` ownership so a submit happens **exactly once**.
- `tui.stop()/start()` (yielding a real terminal) is **deliberately not implemented**: `stop()` carries no command and plugins `spawn({stdio:"inherit"})` themselves, so the child is invisible to our terminal panel — the only alternative is hijacking `spawn`, a new trust surface.

### Correctness fixes

- **Projected message lines kept the old theme colour** (#109): switching themes now replaces `renderedLines` by entryId (the old tail-merge could not recolour earlier loaded pages and could swap a history window for the tail page). The recolour memory compares **content**, so genuinely changed content lets the disk win.
- **A page opened before a plugin registered waited for the next projection or a reload** (#110): the two state-application paths converge into `applyExtensionUiProjection`, and a not-yet-live session does a short bounded retry instead of grabbing the event stream (which used to downgrade the 15s fallback reconcile to 120s).
- **The sidebar counted "host starting" as running** (#111): badge, timer, list and SSE now only count sessions that are really running, so opening an idle session no longer flashes a ~2.5s running marker.
- **PTY lifecycle** (#81): a SIGKILLed parent no longer leaves the worker and shell behind; Windows no longer passes a signal to node-pty (which throws before doing any cleanup); on win32 the terminal asks the worker to exit and only force-kills after a grace period; ping/pong heartbeats cover half-open connections.
- **Dead unread entries** (#95): the sweep decides inside the prefs lock against the **latest** bucket (no whole-bucket overwrite from a stale snapshot), and an empty/unreadable session listing aborts the round instead of wiping unread state.
- **Browser-test injection** (#94): `network route --body` never reaches page-initiated fetches, so the suite now injects an init script wrapping `window.fetch` (GET only; PUT still reaches the server so the #62 leak check stays honest).
