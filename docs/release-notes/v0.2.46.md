# v0.2.46

## 中文

### 渲染异常不再整页白屏

以前任何一次页面渲染期异常都会把整棵树卸掉——你看到的就是**整页白屏**，而且一个字都不留，
问题连反馈都无从下手。现在加了错误边界（页面级 + 根布局级）：出问题时显示的是一屏可读的错误
（错误原文 + digest + 重试/刷新按钮），完整堆栈在浏览器控制台（F12）。

顺带修掉收尾缺陷：SIGTERM 后 8 秒宽限期到点曾用 `exit(1)`，于是每次正常重启都被 systemd 记成
`FAILURE`（`Restart=on-failure` 下还会变成重启循环），也干扰排查。

### 手机端：会话区两边不再多留空白

会话列的上限一直在让出「调宽手柄 + 间距」的宽度，可手机端根本没有手柄——于是内容两边凭空多出
一条空白（500px 视口下每侧约 38px）。现在手机端不让出这段宽度，两侧只剩 16px 内容内边距。

### 手机端：点扩展面板不再弹软键盘

插件面板的键盘捕获元素是会弹软键盘的输入框，而「面板守住键盘」的焦点守卫会在你点面板时把焦点
塞给它——手机上就是键盘顶上来的那一下。手机端现在不抢焦点、不挂焦点守卫（方向键/回车由屏幕
按键条送，不依赖焦点），实测点面板后焦点仍是页面本身。

### 手机端：扩展按键条固定到屏幕底部

屏幕按键条（↑↓←→⏎Esc）改为贴屏幕底部固定（含安全区），并在面板容器上让出同样高度，免得正文
被压在按键条下面。实测：插件自己的页脚按钮正好落在按键条之上；点屏幕 ↓ 能把问卷选项从「苹果」
推到「香蕉」。

## English

### A render error no longer blanks the page

Any error thrown while rendering used to unmount the whole tree — a **blank white page** with not a word
on it, leaving the problem impossible to report. There are now error boundaries (page level and root layout
level): a failure shows a readable error screen (message + digest + retry/reload buttons) and the full stack
goes to the browser console (F12).

A shutdown defect was fixed along the way: the 8-second grace timer after SIGTERM used `exit(1)`, so every
normal restart was recorded by systemd as `FAILURE` (and under `Restart=on-failure` could become a restart
loop), which also muddied diagnostics.

### Mobile: no more extra padding beside the conversation

The conversation column's upper bound kept reserving the width of the resize handle plus its gap, but mobile
has no handle at all — so the content gained a phantom margin of about 38px on each side at a 500px viewport.
Mobile no longer reserves that band; only the 16px content padding remains.

### Mobile: tapping an extension panel no longer raises the keyboard

The panel's key-capture element is an input that raises the soft keyboard, and the "panel keeps the keyboard"
focus guard handed it focus whenever you tapped the panel — that was the keyboard popping up. On mobile the
panel no longer grabs focus and the guard is not installed (arrow keys and Enter come from the on-screen key
bar, which does not depend on focus). Measured: after tapping the panel, focus stays on the page itself.

### Mobile: the extension key bar is pinned to the bottom of the screen

The on-screen key bar (↑↓←→⏎Esc) is now fixed to the bottom edge (safe area included), and the panel container
reserves the same height so the body is not hidden behind it. Measured: a plugin's own footer button sits
right above the bar, and tapping ↓ on screen moves a questionnaire selection from "apple" to "banana".
