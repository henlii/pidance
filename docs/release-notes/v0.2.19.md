# v0.2.19

## 中文

### 新增
- **GPT Codex WebSocket 通道**：会话默认设置新增「模型传输通道」下拉（auto / sse / websocket），写 `settings.json` 的 `transport`。模型 API 下拉加入 `openai-codex-responses`（GPT 快速通道经 WebSocket 直连）。
- **桌面包瘦身**：打包输入剔除 sourcemap、非 win32 SWC 原生残留与 next 调试产物，安装包更小、构建更快（功能无损；仅删调试资产）。

### 修复
- 手机端**锁屏/后台一段时间后界面冻结**：切回前台强制重连 SSE 并重拉会话尾页，冻结期间完成的消息与运行态立即收口，无需手动刷新。
- **队列消息开始执行后会话看不到**（需刷新才见）：follow-up 入队后立即建立 SSE 订阅，Host 自动投递的 run 事件实时投影。
- **压缩后 footer / 上下文占用消失**：压缩收尾与 host 释放竞态导致热状态被清空 —— 不再在加载起始清空上下文占用，顶栏回退磁盘统计，压缩后仍显示。
- **智能体运行中输入 `/` 无命令提示**：内置命令在运行中被整体隐藏导致空菜单 —— 恢复展示，选择后按 follow-up 排队到本轮结束执行。
- **移动端表格内容无法选择**：表格容器显式允许文本选择（user-select: text），长按可选中复制。

### 备注
- `fast`（serviceTier / flex 模式）：上游 SDK 0.84.4 无配置入口（仅 pi-ai 请求层有字段，Agent 层不透传），当前版本无注入点，未落地；可后续随 SDK 升级补。

## English

### Features
- **GPT Codex WebSocket transport**: new "模型传输通道" selector in session defaults (auto / sse / websocket) persisting `transport` in settings.json; `openai-codex-responses` added to the model API dropdowns for the fast GPT channel over WebSocket.
- **Desktop installer slimming**: packaging drops sourcemaps, non-win32 SWC natives and Next dev diagnostics (debug-only assets; no functional impact).

### Fixes
- Mobile UI freezing after lock/background: on tab resume the SSE connection is force-recreated and the session tail reloaded, so messages/runs finished while frozen appear immediately.
- Queued messages not visible once auto-flushed (required refresh): the session now opens its SSE subscription right after enqueue, making Host-flushed runs stream live.
- Context usage / footer bar disappearing after compaction: no longer cleared at load start (host-dispose race); top bar falls back to disk stats.
- Slash `/` palette empty while the agent is running: builtin commands are shown again and queue until the current run ends.
- Mobile table content not selectable: table wrapper/cells now explicitly allow text selection for long-press copy.

### Notes
- `fast` (serviceTier/flex): no config entry point in upstream SDK 0.84.4 (field exists only in pi-ai request options, not plumbed through the Agent layer); deferred until the SDK exposes it.
