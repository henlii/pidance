## 中文

### 最近会话

「显示更多」之后可以收回到默认 5 条。

### 顶栏子会话谱系

面包屑按主/子会话区分：主会话是标题加数量菜单，子会话是可点的父层加当前标题开关。下拉行与侧栏共用运行/等待指示。窄屏超过两段只留首尾。

### 子代理发现

同步 run 目录名支持完整 UUID（Pi 0.68 布局）。父会话文件不再写入时，run 根两层目录戳变化仍会让列表看见新建或删除的子会话。activity 里已有、列表还不认识的子会话会有界补刷（冷却、最多 3 次），不会同一批 id 永不重试。

### 深链打开会话

客户端首帧读浏览器真实 `?session=`，避免水合时空参数冲成新建页。URL 恢复未完成时身份 hydrate 不抢跑；SWR 旧列表不算权威、不会误判 not-found，也不会清掉不在缓存里的 pending。恢复期间用户主动换工作区仍放行。

验收以 Node 单测 + 谱系 SSR 为主；菜单键盘/点击的无头浏览器回归未做。审稿目录 `docs/message-send-*` 未纳入。

## English

### Recent sessions

After “show more”, the list can collapse back to the default 5 items.

### Header lineage

Breadcrumbs distinguish root vs child sessions: the root shows a count menu; a child session shows a clickable parent plus a title switcher. Dropdown rows share the sidebar running/waiting indicators. Narrow viewports keep only the first and last crumbs.

### Subagent discovery

Sync run directory names accept full UUIDs (Pi 0.68 layout). When the parent JSONL stops changing, a bounded two-level run-tree stamp still invalidates the discovery cache so new or deleted child sessions appear. Missing activity ids trigger a bounded list refresh (cooldown, max 3 attempts) instead of never retrying the same set.

### Deep-link session restore

The first client frame reads the real `?session=` from the browser URL so an empty hydration param cannot start a new session. Identity hydrate waits while URL restore is in flight. A SWR cache preview is not an authoritative list (no false not-found) and does not drop pending sessions absent from the cache. A user workspace switch during restore is still applied.

Verification is Node tests plus lineage SSR. There is no headless keyboard/click harness for the lineage menu. Review notes under `docs/message-send-*` are not in this release.
