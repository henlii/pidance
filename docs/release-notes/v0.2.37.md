# v0.2.37

## 中文

### 长会话不再"突然折叠 / 滚动乱跳"

- **过程分组折叠整体删除**：消息一律平铺（compositor 不再产出 processGroup），
  `ProcessDetailsGroup` 连同「进视口才挂载」「上次实测高度缓存」「`messageCount*56 + toolCallCount*24` 估算」
  一起删掉 —— 折叠态与展开态靠猜高度，挂载/卸载时高度一变就是滚动抖动。
- **客户端渲染窗口删除**：`visibleCount` / `getVisibleRenderWindow` / `growVisibleCountOnAppend` /
  `shrinkVisibleCountOnPlanShrink` 全部退役，已加载消息全量渲染。
- **手写 prepend 补偿删除**：`pendingCompensation` 事务、reading anchor、plan 签名比对、
  recapture 开关一并去掉，改为按跟随状态切换 `overflow-anchor`（阅读态交给浏览器保持视口内容）。

### 消息位置按「运行时状态 + 落盘顺序」统一锚定

- 之前引导气泡的**渲染顺序**用 `_steerOptimistic`、**落位顺序**用 `streamState.isStreaming`，两个判据在
  「上一步已结束、下一步还没出首帧」的空窗里不一致 → 引导先显示在思考下面、思考结束后又跳到前面。
  现在两处共用 registry 按 `agentRunning` 打的同一个标记（record 与 message 都写），位置不再跳。

### 向上翻页

- **不再无限加载**：更旧一页落进时间线后，用 `scrollHeight - scrollTop` 精确恢复视口（不猜高度），
  哨兵随之离开视口。
- **分页 200 → 100 条，并把窗口起点对齐到最近的提问**（最多再向前扩 100 条）：阅读上每页从提问开始，
  同时避免超大轮把单页撑成几千条。

### 工具块与扩展面板

- **运行中的工具块整行扫光动画**（非颜色信号：浅色主题里运行色与成功色曾非常接近，光看色相分不出）。
- **运行色统一为橙**，与成功绿、失败红一眼可分（两套青绿主题原本是青绿，和成功绿撞色）。
- **运行阶段提示合并成一行**，并且不再与工具块重复（工具执行中只由工具块扫光表示）。
- **扩展面板（问题块）去掉「收起/展开」「关闭」按钮**：标题行整行可点折叠，收起态只留一行标题、
  不再渲染正文与底栏；扩展自绘面板（无底栏那类）补了底栏「取消」（走 TUI 中断）。

### 侧栏

- 点「未分组会话」不再把滚动条拽到「最近会话」处：同一会话会同时出现在两个区，而选行只取 DOM 里
  第一个匹配，且折叠状态也会触发"选中行回看"。

## English

### Long sessions: no more sudden collapsing or jumping scroll

- **Process grouping removed**: messages render flat again (`composeChatPlan` no longer emits `processGroup`),
  and `ProcessDetailsGroup` is gone along with its viewport-gated mounting, measured-height cache and
  `messageCount*56 + toolCallCount*24` estimate — guessing heights is what made the scroll jump.
- **Client render window removed**: `visibleCount`, `getVisibleRenderWindow`, `grow/shrinkVisibleCountOnPlanShrink`.
- **Hand-written prepend compensation removed**: the pending-compensation transaction, reading anchor and plan
  signature comparison are replaced by toggling `overflow-anchor` with the follow mode (the browser keeps the
  viewport stable while reading).

### Message placement anchored on run state + disk order

- Steer bubbles used one predicate for rendering order (`_steerOptimistic`) and another for insertion
  (`streamState.isStreaming`); in the gap between two steps they disagreed, so a steer bubble rendered below the
  running thinking block and then jumped above it. Both now share the single flag registry derives from
  `agentRunning` (written to both the record and the message).

### Paging upward

- **No more runaway loading**: after an older page lands, the viewport is restored from
  `scrollHeight - scrollTop` (no height guessing), which moves the sentinel out of view.
- **Page size 200 → 100, with the window start aligned to the nearest user question** (extending at most 100 more):
  reading starts on a question, and an oversized turn cannot inflate a single page into thousands of messages.

### Tool blocks and extension panels

- **Running tool blocks sweep the whole header row** (a non-colour signal: in light themes the running and success
  hues were too close to tell apart).
- **Running status colour unified to orange**, clearly distinct from success green and failure red.
- **Run-phase hints merged into a single line** and no longer duplicated by the tool block itself.
- **Extension panels lost their collapse/close buttons**: the whole title row toggles collapse, and the collapsed
  state renders neither body nor footer. Self-drawn extension panels (which have no footer) gained a footer
  "Cancel" that sends the TUI interrupt.

### Sidebar

- Clicking "Ungrouped sessions" no longer drags the scroll position to "Recent sessions": one session can appear in
  both sections while row lookup took the first DOM match, and collapse changes also triggered the
  "scroll the selected row into view" pass.
