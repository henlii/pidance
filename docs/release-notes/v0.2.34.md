# v0.2.34

包：`@henlii/pidance` · CLI：`pidance`

## 中文

### 侧栏与会话归属

- **去掉 Git worktree 分组，项目 = 目录（一对一）**：服务端不再解析 `git rev-parse --git-common-dir` 把 linked worktree 折回主仓，`projectRoot` 恒等于 `cwd`，会话列表不再返回 `worktreeBranch`。同一仓库的两份 checkout 就是两个项目；侧栏项目下直接是会话行。随之删除 `/api/worktrees`、worktree 切换/新建/删除 UI、按项目预加载的快照与 identity 回写。
- **引导页项目下拉改用同一个项目列表**：原先按「最近 12 个会话的 cwd」聚合再并上项目列表，会出现侧栏根本看不到的目录；现在候选 = 项目列表（目标不在列表里时补一个临时项，保证「下拉显示的目标 = 实际建会话的目录」）。
- 项目列表里的项目即使还没有会话也持续显示；删除 `collapsedWorktreePaths` 偏好（旧数据里的该键会被忽略，不再回写）。
- **已知边界（下一版改）**：不在项目列表、又没被选中的目录，其会话目前在侧栏整体不显示（最近区、置顶区、全文搜索命中、归档视图都按「项目列表 ∪ 当前选中目录」过滤）。计划改成底部的「未分组会话」区，让这些会话有归宿。

### 聊天与文件

- **会话内容不再被落后的磁盘页截断**：同会话尾页重载（`agent_end`、切回前台触发）遇到「这次磁盘读落后于内存时间线」时，原实现会用旧页替换重叠段之后，于是刚显示出来的新消息被抹掉，必须刷新整个网页才恢复。现在识别落后页并保持时间线不动（落后页仍可用于补齐更旧历史）。
- **手机端文件详情有了承载点**：≤640px 的二级面板原先被 `display:none` 无条件隐藏，而唯一的文件查看器就挂在它里面 —— 手机上点文件只有状态变化。现在二级面板是与一级右栏同规格的全屏抽屉（`z-index` 盖在右栏之上，内层铺满、窄屏隐藏拖拽手柄），打开文件时不再顺带叠一层右栏，关闭后回到下一层；桌面（≥641px）行为不变。
- **变更面板的 diff 竞态**：快速切文件时旧响应可能后到并覆盖新文件的 diff。新增「只认最新一次请求」守卫（`lib/latest-request.ts`），变更面板与文件查看器共用。
- **失效的授权根不再让保存整体失败**：保存时对 `allowedRoots` 逐个 `realpath`，其中任一根不存在就整体报「目标路径不存在」。现在跳过失效根（读文件、新建文件本来就是这么做的）。

### 子代理

- **fork 上下文的子会话能被发现了**：`context: fork` 的子会话写在父会话目录下的 `forks/`，而发现器只认 `<runId>/run-N/session.jsonl` 与 `async-<uuid>/*.jsonl`，导致这些子会话不在会话列表里 → 顶栏谱系下拉看不到、运行状态也不显示（worker / oracle / advisor 默认就是 fork）。现在补上第三种布局；用户自己在 Pidance 里 fork 出的会话是同级文件，不会被误判成子代理。
- **子代理跑完会唤起父会话**：宿主在 `agent_settled` 时立即销毁（释放跨进程 writer 租约），子代理稍后完成时已经没有 owner 宿主可以投递，结果只写进 transcript、不触发新一轮。现在「本会话名下还有进行中的子代理」期间不销毁宿主；run 记录超过 15 分钟没更新（进程被杀、记录残留）则不再据此保活。同时确认：子代理在跑时，会话列表的父会话行显示「运行中」与计时。
- **异步状态面板按 TUI 的行结构渲染**：pi-subagents 在宿主报 rpc 模式时发的是一行机器快照 `PI_SUBAGENT_ASYNC_JSON:{…}`，之前没有解码器、被当普通文本贴在输入框上方。现在解析它并渲染成「异步子代理 <agent> · 后台」＋状态字形/时长/当前工具/轮数，位置仍是输入框上方；不再显示原始载荷，也不再显示终端键位提示（`↓/← to inspect`）。

### 文档

- 新增《界面分区：Pidance Web 与 Pi TUI 对照》（`docs/ui-vs-tui.md`）：三个面的分区图、部件映射表、扩展 UI 槽位现状与缺口、刻意分叉清单，以及「改了什么 → 回来更新哪节」的维护清单。

### 已知边界

- 「未分组会话」区尚未实现：不在项目列表里的会话目前在侧栏不显示（见上）。
- **（已更正）** 本条原先记为「打开一个正在跑子代理的会话时，输入框上方的扩展面板要等下一次更新才出现（widget 只走 SSE 实时投影，状态水合不带它）」——实测是误判：状态水合一直会带上 `extensionWidgets`，新开页面能直接看到面板。结论已在 `docs/ui-vs-tui.md` 更正。
- 桌面壳 bridge（托盘「桌面版设置」、桌面通知）尚未接线；Electron 壳仍只连 31415，本次发布后其内置服务仍为上一版（桌面制品单独构建）。
- 外部把会话变短（另一标签页退回 leaf）时，后台刷新不再缩短已显示的时间线；显式导航与冷加载仍会。
- 会话仍在运行时，磁盘快照不会覆盖更新的流式内容（既有语义未变）。

## English

### Sidebar and session ownership

- **Git worktree grouping removed; one directory = one project**: the server no longer resolves `git rev-parse --git-common-dir` to fold linked worktrees into the main repo. `projectRoot` always equals `cwd`, the list no longer returns `worktreeBranch`, and two checkouts of the same repository are two projects. Session rows now sit directly under the project row. `/api/worktrees`, the worktree switcher/create/remove UI, the per-project preload snapshots and the identity write-backs are gone.
- **The new-session guide now uses that same project list**: it used to aggregate the 12 most recent session cwds on top of the project list, which surfaced directories the sidebar never shows.
- Projects stay visible even with no sessions yet; the `collapsedWorktreePaths` preference was dropped (old values are ignored and never rewritten).
- **Known gap (next release)**: sessions whose directory is neither in the project list nor currently selected are still hidden from the sidebar (recent, pinned, full-text hits and the archive view all filter by "project list ∪ selected directory"). A bottom "ungrouped sessions" section is planned.

### Chat and files

- **Session content is no longer truncated by a lagging disk page**: when a same-session tail reload (`agent_end`, tab-return) read disk before the last append landed, the merge replaced everything after the overlap and silently dropped the newest messages until a full page refresh. Lagging pages are now detected and the timeline is kept intact (they are still usable for older history).
- **File detail on phones**: the secondary panel was hidden with `display:none` at ≤640px while the only file viewer lived inside it, so tapping a file did nothing. It is now a full-screen drawer above the right panel (same shape as the workspace drawer), and opening a file no longer stacks a second drawer; desktop layout is unchanged.
- **Diff race in the changes panel**: a late response could overwrite the diff of a newly selected file. A "latest request wins" guard (`lib/latest-request.ts`) is now shared by the changes panel and the file viewer.
- **A stale allowed root no longer fails the whole save**: the save path `realpath`ed every allowed root and reported "target path does not exist" when any of them was gone. Stale roots are skipped now.

### Subagents

- **Fork-context children are discoverable**: `context: fork` children are written to `forks/` inside the parent session directory, while the discovery only recognised `<runId>/run-N/session.jsonl` and `async-<uuid>/*.jsonl`. Those children never appeared in the session list, so the header lineage dropdown could not show them and no running state was reported (worker/oracle/advisor default to fork). The third layout is now supported; user-created forks in Pidance are sibling files and are not misclassified.
- **A finished subagent now wakes the parent session**: the host was disposed immediately on `agent_settled` (to release the cross-process writer lease), so a later completion had no owning host to deliver into and only landed in the transcript. The host is now kept alive while this session owns a running subagent (runs whose record has not been updated for 15 minutes no longer hold it). While a subagent runs, the parent row in the session list also shows "running" with its timer.
- **The async status panel is rendered like the TUI**: pi-subagents sends a one-line machine snapshot (`PI_SUBAGENT_ASYNC_JSON:{…}`) to rpc-mode hosts. It used to be printed verbatim above the input box; it is now decoded and rendered as "async subagent <agent> · background" with state glyph, elapsed time, current tool and counters. Raw payloads and terminal key hints (`↓/← to inspect`) are no longer shown.

### Documentation

- New "Interface regions: Pidance Web vs Pi TUI" (`docs/ui-vs-tui.md`): region diagrams for all three surfaces, component mapping tables, extension-UI slot status and gaps, deliberate divergences, and a maintenance checklist.

### Known limitations

- The "ungrouped sessions" section is not implemented yet; sessions outside the project list are hidden from the sidebar.
- **(corrected)** This entry originally read "when opening a session that already runs a subagent, the widget above the input box only appears on the next update (widgets are delivered through the live SSE projection, not through state hydration)" — that was a misreading: state hydration has always carried `extensionWidgets`, so a freshly opened page does show the panel. The conclusion is corrected in `docs/ui-vs-tui.md`.
- The desktop-shell bridge (tray settings, desktop notifications) is still unwired; the Electron shell keeps talking to 31415 and its bundled service stays at the previous version until the desktop artifact is built separately.
- When another client shortens a session (e.g. moving the leaf back), a background refresh no longer shortens the displayed timeline; explicit navigation and cold loads still do.
- While a run is active, a disk snapshot never overwrites newer streaming content (unchanged semantics).
