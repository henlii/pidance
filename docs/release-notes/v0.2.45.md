# v0.2.45

## 中文

### 插件按键说明搬到「关于」页

插件注册全局按键监听（`onTerminalInput`）时，Pidance 会在会话里发一条英文能力提示，说明按键只在三个
窄窗口里送达。这条提示是注册时发一次、并由面板状态回放的，所以**每次打开会话都会再看到一次**。

说明性内容应当待在「关于」页，而不是塞进会话通知。这一版：

- 删掉这条提示（`notifyLimitedSupport` 及其调用）；按键的实际行为一字未改。
- **「关于」页新增「扩展界面能力」一节**：对齐原则，加上三个按键窗口逐条列出，以及窄视口屏幕按键条
  的说明。以后同类的「说明」都加在这里，不再发会话通知。
- 保留另一条运行时通道（`tui.stop()/start()` 这类真正不支持的能力仍会可见降级），它只记进只读快照，
  供晚订阅的页面回放。

## English

### Plugin keyboard notes moved to the About dialog

When a plugin registers a global key listener (`onTerminalInput`), Pidance used to emit an English capability
notice into the session explaining that keys only arrive in three narrow windows. That notice fires at registration
time and is replayed from the panel state, so it reappeared **every time a session was opened**.

Explanatory text belongs in the About dialog, not in session notices. This release:

- Removes that notice (`notifyLimitedSupport` and its call site); the actual key behaviour is unchanged.
- Adds an **"Extension UI capabilities"** section to the About dialog: the alignment principle, the three key
  windows listed one by one, and the narrow-viewport on-screen key bar. Future notes of this kind go here instead
  of being emitted into a session.
- Keeps the other runtime channel (genuinely unsupported abilities such as `tui.stop()/start()` still degrade
  visibly); it is only recorded into a read-only snapshot for pages that subscribe later.
