# v0.2.21

## 中文

### 运行中状态与计时
- **计时只算本轮执行**：从发出消息到智能体结束。host 保活、writer 租约不再让侧栏圆点和秒数继续走。
- **跨实例占用有提示**：另一个 Pidance（例如 31415）还占着会话时，31416 打开会看到「另一个实例正在使用」，不能再无声失败。
- **发送失败不再留假气泡**：被占用或请求被拒时，提示错误，文字回到输入框，聊天区不留下「发出去了」的假消息。

### 其它
- 对端释放占用后（切回前台或约 5 秒）输入框会恢复。
- 桌面浏览器、手机、Electron 共用同一套提示与失败恢复。

## English

### Running status and timer
- **Timer is this run only**: from send to agent_end. Host keep-alive / writer leases no longer keep the sidebar badge ticking.
- **Cross-instance lock is visible**: if another Pidance process already holds the session, opening it shows “in use by another instance” instead of failing silently on send.
- **Failed send drops the fake bubble**: lock/reject shows an error, restores the draft, and does not leave an unsent user message in the transcript.

### Other
- The composer returns after the other instance releases (foreground return or ~5s).
- Desktop browser, mobile, and Electron share the same lock notice and failure recovery.
