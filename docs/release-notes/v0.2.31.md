## 中文

### 运行结束时的阅读位置

会话还在跑时把滚动条离开底部，结束后视口会跟着跳一截：最后一轮收成过程组时，渲染窗口起点被往前拽，过程组还可能先换成矮占位。本版：

- 计划变短时同步收可见窗口，起点不再前移。
- 最后一轮过程组首帧直接挂真实内容；更早的历史组仍先占位、进视口再挂载。
- 已松手阅读时按块身份补回偏移，不把人吸回底部。

闸门验收（专用测试会话，不写用户 JSONL）：桌面 / 窄屏，旧轮长短过程、当前过程内部。贴底跟随时仍钉底。尚未覆盖：切会话 A→B→A 的旧回调、贴底附近松手后再结束。

### 发送、草稿与队列

- 乐观用户气泡按提交身份确认，长会话尾页截断不再叠两条；刷新后仍是一条。同文两次真发仍是两条。
- 带图发送会先清空输入区；成功不把原文案写回，失败才还给原来的会话草稿。
- 队列在 run 结束后不再等所有 SSE 客户端关掉才投递。中止 / hold 仍不自动投。

### 思考 / 工具块与斜杠命令

- 折叠仍显示流式或首行预览；展开后标题行只留名称，正文从第二行起。
- 标签改为 `思考·` 与真实工具名（如 `Bash·`），整条标题可点。
- 运行中的 `/btw` 走 SDK `prompt()`，与 Pi TUI 一样不进主时间线、不排队。

### 其它界面

- 扩展面板（含 `/btw` 自定义层）与语义对话框共用 GUI 外壳；选中文字时 Ctrl/Cmd+C 复制，关闭仍发协议中断。
- 换工作区会关掉未改过的文件页签；未保存的留下并走原有确认。
- 思考档位不再被热状态误写成更浅的一档（例如 ds4.1f 显示 high、实际仍是 max）。
- 最近会话「显示更多」之后可以收回到默认条数。

谱系顶栏、侧栏导航等未完成改动未纳入本版提交。

## English

### Reading position when a run ends

Scrolling away from the bottom while a session was running could jump the viewport at settle: the last turn collapsed into a process group, the render window’s start index moved backward, and the group could first mount as a short placeholder. This release:

- Shrinks the visible window with the plan so the start index stays put.
- Mounts the last turn’s process group as real content on the first frame; older groups still lazy-mount.
- Restores the in-view block when the user has released follow, instead of pinning to the bottom.

Gated browser checks (dedicated test session, no writes to user JSONL): desktop and narrow, older-turn long/short process, and in-process reading. Stick-to-bottom follow is unchanged. Not covered: stale A→B→A callbacks, or releasing near the bottom then settling.

### Send, drafts, and queue

- Optimistic user bubbles confirm by submission identity; a truncated tail page no longer stacks a duplicate. Two real same-text sends stay two.
- Image send clears the composer first; success does not rewrite the editor, failure restores the original session draft.
- The follow-up queue no longer waits for every SSE client to disconnect after a run. Abort/hold still does not auto-deliver.

### Thinking / tool chrome and slash commands

- Collapsed blocks still show the streaming or first-line preview; expanded title is name-only, body from line 2.
- Labels are `思考·` and real tool names (e.g. `Bash·`); the whole header is clickable.
- `/btw` while running uses SDK `prompt()`, matching Pi TUI (no main-timeline bubble, not queued).

### Other UI

- Extension panels (including `/btw` custom) share GUI chrome with semantic dialogs; Ctrl/Cmd+C copies when text is selected; Close still sends a protocol interrupt.
- Switching workspace closes clean file tabs; dirty tabs keep the existing confirm flow.
- The thinking control is no longer overwritten to a shallower level by hot state (e.g. ds4.1f showing high while send stayed max).
- Recent sessions can collapse back to the default count after “show more”.

Unfinished lineage header and sidebar navigation work is not in this commit.
