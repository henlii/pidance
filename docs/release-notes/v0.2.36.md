# v0.2.36

## 中文

### 显示口径：只有智能体正文默认展开

会话时间线里**只有智能体直接输出的正文默认展开**，其余一律可折叠且**默认收起**：thinking、工具调用、
过程分组（一轮的思考/工具/子代理回复）、压缩块、分支摘要、扩展自定义消息、子代理通知。

- **过程分组只包中间过程**，每轮末尾那条正式回答由 compositor 渲染在组外 —— 收起不会藏掉智能体输出。
- 压缩块与分支摘要改成标题行整行可点（`aria-expanded`），一段压缩摘要经常上千像素，默认收成一行。
- **折叠归「槽位外壳」所有**：所有 `setWidget` 部件（含 pi-subagents 的异步子代理这种机器载荷）
  共用同一个卡片模板，折叠按钮、`aria-expanded`、按 widget key 持久化的折叠状态只有一处实现 ——
  任何插件用这个槽位都自动能折叠。标题也由外壳给（机器载荷用友好名 + 「后台 / N queued / 截断」副标题）。

### 侧栏

- **fork 子会话按独立会话平铺**：Pi 原生 fork 出来的会话与父平级各占一行，不再嵌在父行下。
  此前会折叠子行，而 fork 连标题一起复制，看起来像「同一个会话显示了好几行」。
- 子代理消息块显示友好标题（子代理通知）而不是内部 customType，头部折叠按钮默认收起。

### 会话内容区宽度可拖拽、按比例记忆

- 宽度 = **内容区可用宽度 × 比例**，再夹到 `[1000, 1600]`：宽屏到 1600 封顶后只长两侧空白；
  窄到下限后只缩空白；空白归零后内容才跟着缩。
- **存比例**，窗口或侧栏尺寸变化自动重算；把手贴在内容列左右缘（`role="separator"`，
  拖任一侧对称改宽、被拖那条边跟手；双击回默认；键盘 Arrow / Shift+Arrow / Home / End）。
- 宽度落在 CSS 变量 `--pidance-chat-column-width` 上、只在 AppShell 写一处，
  消息列 / 输入栏 / 扩展面板 / widget / 底栏共用 —— 同宽同中心线。

### 文件：图片预览「下载原图」之后可以「另存为」

- 「下载原图」保持浏览器下载（落在浏览器自己的下载目录）；点过之后按钮变成「另存为」。
- 「另存为」弹目录选择框（复用 `/api/cwd/browse`，默认家目录），由**服务端**把原文件复制到所选目录：
  **原文件保留在原位**，同名不覆盖、自动加 ` (n)` 后缀（已带序号的名字继续往后编号）。
- 只有拿得到服务端路径的媒体才有「另存为」；纯 base64 内嵌图没有可复制的源文件。

### 测试基础设施

- 浏览器回归套件登录不再勾选「信任本设备」，不再每次运行都堆一条 10 年期设备记录。

### 已知边界

- 「另存为」的目录选择只在 Web 端；桌面壳（Electron）用的是同一个页面，因此行为一致。
- 内容区宽度是**本机**偏好（与其它面板宽度同口径），不跨端同步。
- 浏览器回归套件里的 `B4：未读时钟跨端` 为已知易抖用例，单独跑，主套件 18 例。
- Electron 壳冒烟只在 CI（Windows 构建）里跑；本机 `desktop/` 无 node_modules。

## English

### Display policy: only the agent's own prose is expanded by default

In the conversation timeline **only the agent's directly emitted prose is expanded by default**.
Everything else is collapsible and **collapsed by default**: thinking, tool calls, process groups
(the thinking/tools/subagent replies of a turn), compaction blocks, branch summaries, extension
custom messages and subagent notices.

- A **process group only wraps the intermediate steps**; the final answer of each turn is rendered
  outside the group, so collapsing never hides the agent's output.
- Compaction and branch summary blocks became click-anywhere headers (`aria-expanded`); a compaction
  summary is often thousands of pixels tall and now collapses to one line.
- **Collapsing belongs to the widget slot, not to the content**: every `setWidget` part (including
  pi-subagents' machine-payload async panel) shares one card template, so the chevron, `aria-expanded`
  and the per-widget-key persisted state live in exactly one place — any plugin using that slot gets
  collapsing for free. The title is provided by the shell as well (friendly names plus
  “background / N queued / truncated” subtitles for machine payloads).

### Sidebar

- **Pi-native fork children are shown flat**: a forked session sits next to its parent as an ordinary
  row instead of being nested underneath it. A fork copies its parent's title, so nesting made one
  conversation look like several rows.
- Subagent message blocks show a friendly title (subagent notice) instead of the internal customType,
  with a header chevron that starts collapsed.

### Draggable, ratio-based conversation width

- Width = **available content width × ratio**, clamped to `[1000, 1600]`: on wide screens it caps at
  1600 and only the side margins keep growing; near the lower bound only the margins shrink; once the
  margins hit zero the content itself shrinks.
- The **ratio** is what gets stored, so window or sidebar resizes re-derive the width automatically.
  Handles sit on both edges of the content column (`role="separator"`; dragging either side resizes
  symmetrically with the dragged edge following the pointer; double-click resets; keyboard
  Arrow / Shift+Arrow / Home / End).
- The width lives in one CSS variable (`--pidance-chat-column-width`) written only by AppShell and
  shared by the message column, input bar, extension panels, widgets and footer — same width,
  same centre line.

### Files: “Save as” after “Download original” in the image preview

- “Download original” still downloads through the browser (into the browser's own download folder);
  once clicked, the button becomes “Save as”.
- “Save as” opens a directory picker (reusing `/api/cwd/browse`, defaulting to the home directory)
  and the **server** copies the original file into the chosen directory: **the original stays where it
  is**, existing files are never overwritten (a ` (n)` suffix is appended, and an already-numbered name
  keeps counting up).
- Only media with a real server-side path offers “Save as”; a purely base64-embedded image has no source
  file to copy.

### Test infrastructure

- The browser regression suite no longer ticks “trust this device” when logging in, so each run no
  longer piles up a 10-year device record.

### Known limitations

- The “Save as” directory picker is web-only; the Electron shell loads the same page, so behaviour
  matches there.
- The conversation width is a **machine-local** preference (same policy as the other panel widths);
  it does not sync across devices.
- `B4：未读时钟跨端` in the browser regression suite remains a known flaky case and is run on its own;
  the main suite runs 18 cases.
- The Electron smoke test only runs in CI (Windows build); `desktop/` has no installed node_modules
  on this machine.
